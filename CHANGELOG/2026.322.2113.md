# 2026.322.2113 — feat(prompt): add the R11 DESIGN-conformance check and make the session footer mandatory

## Summary

This is the producer leg of opencharly/opencharly#1119. It changes the validator's committed rulebook (`AI_REVIEW_PROMPT` default in `charly.yml`) in two ways. Head: `04534b61da009efc4fdceff45e7b1e35fdd7f3ef` — 1 file, +31 −12.

1. **New check R11 — conform to DESIGN (the ratchet).** The heading moves from `R0–R10` to `R0–R11`. R11 has four parts:
   - A change that adds or reshapes a field, shape, kind, verb, capability or mechanism cites the D-ids it touches in `## Rulebook compliance`. For each one it states conforms, amends DESIGN, or design debt filed.
   - A change never moves code further from DESIGN.
   - A change to `DESIGN.md` / `DESIGN.cue` / `design/` carries the `design-check` output and a maintainer sign-off.
   - Untouched non-conforming code is debt, not a finding.
2. **The session footer is mandatory, for agents and bots alike.** COORD and the identity-footer note require `*Agent: <slug> · <Harness> session <id>*` (slug and id in backticks) on every agent-authored PR body and comment, not only on contended scopes. The model-free generator clause requires the same line in its bot form: the workflow as the slug, `GitHub Actions` as the harness, and the run id as the session. Then every attributed PR traces to the session or run that wrote it. The clause no longer names the umbrella `sync.yml` bot, which was retired in opencharly/opencharly#375. The bot change itself is opencharly/marketplace#626.

After this merges, the org variable `AI_REVIEW_PROMPT` is set from the merged file, byte for byte, as this repo's `AGENTS.md` requires ("a drifted copy is the two-rulebooks defect"). The operator directed this in the session that authored the PR. The umbrella PR for #1119 then adds the matching `R11` row to `AGENTS.md` "What the validator checks", and `check-validator-rule-map.mjs` checks that the ids agree.
