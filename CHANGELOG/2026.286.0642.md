# 2026.286.0642 — fix(ci): run the config gate on the org-pinned engine; retire the stamp-era workaround (opencharly/.github#162)

## Summary

The config gate ran the **wrong engine**. `.github/workflows/ci.yml` installed the **latest** `opencharly/charly` release (`gh release download` with no `--tag`) for `charly box validate`, while a second step only *verified* the org pin `vars.CHARLY_VERSION` — so this repo's contract was validated by an engine no gate ever runs (the `opencharly/.github#126` class that the same file's own comment cites). It existed for one reason: the pin of that day (`v2026.271.0950`) predated the config-stamp retirement (`charly#754` / umbrella `#340`) and rejected this stamp-less contract.

**That reason is gone.** Measured 2026-10-13, in a session worktree off fresh `action-review@main` (`fb93502`), with the pinned release:

```console
$ gh variable list --org opencharly --json name,value --jq '.[]|select(.name=="CHARLY_VERSION")|.value'
v2026.278.0912

$ CHARLY_PLUGIN_DIR=/tmp/pin278/plugins /tmp/pin278/bin/charly box validate
charly box validate: OK — checked 5 candies, 7 distros, 7 builders; 0 warnings, 0 errors
rc=0
```

**What changes:**

1. **One engine in the job: the pin.** The step downloads the pinned release's **binary and plugins**, puts them on `PATH` and exports `CHARLY_PLUGIN_DIR`, and keeps the assertion that the release's binary reports the version the pin names. The config gate therefore runs `charly box validate` with the same engine the review gate runs.
2. **The latest-release install step is deleted** — its only consumer was `box validate` (R2: one path, one engine; the step count goes down).
3. **Both stale paragraphs are replaced with the measured truth** — `.github/workflows/ci.yml` and `AGENTS.md` carried the same false claim (that the pin still rejects the contract and that moving `box validate` is "held by the operator on `opencharly/.github#162`"). R5: the retired workaround is stated as retired; the claim-keyed grep below is clean in both files.

Driver: `opencharly/.github#162` (its consequence (1) is discharged — the pin advanced past the retirement — and its consequence (2), the unpinned config gate, is what this PR closes).
