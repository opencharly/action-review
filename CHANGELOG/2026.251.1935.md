# 2026.251.1935 — ci+gate: resolve charly by absolute path within the bootstrap step

## Summary

The bootstrap CI run failed at "Install charly" with `charly: command not found` (exit 127). RCA from the run log: `GITHUB_PATH`/`GITHUB_ENV` updates apply to **subsequent** steps, not the current one — the step's trailing `charly version` executed before PATH included the downloaded binary. Same latent bug in the gate workflow's `charly review --self-test`. Fix in both files: call the installed binary by absolute path within the same step (`"$GH/bin/charly"` / `"$D/bin/charly"`); subsequent steps use PATH as before.

Files: `.github/workflows/ci.yml` (1 line), `.github/workflows/pr-validator.yml` (1 line).
