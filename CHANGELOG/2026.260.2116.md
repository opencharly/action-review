# 2026.260.2116 — docs(a1): define the model-free bot-body attribution form

## Summary of changes

**MAINTAINER SIGN-OFF: the repository owner (atrawog) authorized this A1 amendment in a comment
on this PR** (GitHub forbids self-approval, so the comment is the durable, verifiable sign-off).
This followed the org validator blocking the nightly sync/refresh generator footers twice; the
validator itself named this amendment as the conforming route ("land a rulebook amendment with
maintainer sign-off that defines the non-model form").

A1 as written mandates only the AI-authored form
`*Assisted-by: <Harness> <Provider Full Model Name> (<confidence>)*`. A PR body emitted by a
fixed, model-free CI `printf/echo` block (the nightly `sync.yml` / `refresh.yml` bots) has
neither an AI provider nor an AI model, so that form cannot be truthfully filled — and two
attempts to fill it were correctly blocked: an `N/A` placeholder (an invented A1 sub-rule) and a
runner-image stamp (`ubuntu-latest`, a runner label, not a model). The `prompt/validator.md`
diff adds the explicit model-free form and forbids both dodges:

```
- **A MODEL-FREE bot body — the `<Harness> <Runtime>` form.** … Such a body MUST END with the
  italicized `*Assisted-by: <Harness> <Runtime> (<confidence>)*` line — e.g.
  `*Assisted-by: GitHub Actions ubuntu-latest (fully tested and validated)*` … Do NOT fabricate
  an AI model name in the `<Provider Full Model Name>` slot, and do NOT cite this clause to
  justify an `N/A` placeholder: either the body is AI-authored (use the AI form) or model-free
  (use this form), never a hybrid.
```

This file (`prompt/validator.md`) is the SINGLE authoritative copy: the org gate reads it from
`main` at `REVIEW_PROMPT_PATH` (`dotgithub/.github/workflows/pr-validator.yml` →
`opencharly/action-review@main:prompt/validator.md`), and a repo-wide grep confirms it is the
only copy of the clause. Once this merges, the two generator PRs (opencharly/opencharly#213,
opencharly/marketplace#310) can land with a truthful footer.

**Closes / relates to:** the blocked opencharly/opencharly#213 and opencharly/marketplace#310.
