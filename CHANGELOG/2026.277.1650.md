# 2026.277.1650 — fix(config): drop three AI_REVIEW_* knobs the review engine does not read

## Summary

`charly.yml` declares three `AI_REVIEW_*` knobs for which the review engine this repo runs has **no production reader**, and which nothing else in this repo consumes. Dead configuration is not harmless: each name tells an operator that a turn budget, a tool-result cap or a retry bound is in force while nothing reads it. The caps that actually bound a run are `AI_REVIEW_ATTEMPT_TIMEOUT` (whole request) and `AI_REVIEW_MAX_TOKENS` (generation) — both stay, untouched, and both are read by the engine.

The engine is the `plugin-review` charly plugin this repo pins: `@github.com/opencharly/plugin-review/candy/plugin-review:v2026.270.1323`. The readers of all three names went with the two loops deleted from that engine — the tool-calling loop and the per-attempt retry loop. This change removes the three names from every live place in this repo that declares or forwards them, in one change (R5 — a retired mechanism's declaration goes with it).

Closes #16, whose Scope items 1, 2 and 4 this diff discharges item for item.

**Head:** `3d80f1e` — 4 files, **+1/−13**.
